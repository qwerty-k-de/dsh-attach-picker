# assets

把你的真实截图放在这里（PNG）：

- `assets/screenshot-1.png` — 主界面：输入框工具栏里的图片按钮
- `assets/screenshot-2.png` — 系统文件选择器弹出
- `assets/screenshot-3.png` — 选中的图片进入草稿图片栏 / 校验提示

然后在仓库根创建 `screenshots.json`：

```jsonc
["assets/screenshot-1.png", "assets/screenshot-2.png", "assets/screenshot-3.png"]
```

规则：1–8 张；相对路径必须在本仓库内；市场（dsh-market）会展示为 App Store 式轮播。
